# Prototype — Version 6 (frozen)

Exact copy of the approved SRS Steel Desk prototype (Version 6, 22 Sept 2026), as published on claude.ai.
This folder is a reference snapshot. Do not edit it — the production app is built elsewhere in this repo.

- final.html — the complete single-file app (open in any browser)
- p0.js — screen text in English / Hindi / Hinglish
- p1.html — page shell and styles
- p2.js — calculations and data (weight, cutting, GST/kacha, khata, slip numbers)
- p3.js — screens and button actions
- g0.js — Steel Guide content
